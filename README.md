# 🧠 Algorithms & Problem Solving

Личный репозиторий с решениями алгоритмических задач, олимпиадных кейсов и классических алгоритмов на Python. Проект пополняется по мере решения новых задач.

---

## 📂 Структура репозитория

Файл,Название задачи,Тематика / Описание,Сложность
1.py,Two Sum (Два числа в сумме),"Поиск пары индексов чисел, дающих в сумме target",O(n²)
2.py,Queen Attack (Атака ферзя),"Проверка взятия фигуры по горизонтали, вертикали и диагоналям",O(1)
fibo.py,Fibonacci (Рекурсивный),Базовое нахождение N-го числа Фибоначчи через рекурсию,O(2ⁿ)
fibo2.py,Fibonacci (Итеративный),Вычисление чисел Фибоначчи в цикле без рекурсии,O(n)
knight.py,Knight's Move (Ход коня),Проверка допустимости хода шахматного коня на доске,O(1)

---

## 🚀 Запуск решений

Для запуска любого из решений достаточно стандартного интерпретатора Python 3:

```bash
python3 fibo.py

```

или

```bash
python3 knight.py

```
